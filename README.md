# DoodleDev

A visual design editor for the web. Draw shapes, paths, text and images on a canvas, then export your design as standalone HTML and CSS or a Web Component.

**[Explore DoodleDev](https://doodledev.app/about/) · [Open Editor](https://doodledev.app/)**

Currently in public preview. Free to use. Use a desktop browser; no account is needed.

[![DoodleDev editor welcome screen with options to start a design, open a project or explore Game Boy Color and iPod presets](assets/doodledev-welcome-1920x1080.png)](https://doodledev.app/)

## Features

- **Drawing tools.** Combine shapes, paths, text, icons and images on the canvas, with snap to grid.
- **Shape tools.** Build new shapes from overlapping ones, mask layers and turn strokes into outlines.
- **Type on a path.** Set text along any path.
- **Styling.** Colours, gradients and image fills.
- **Effects.** Shadow, glow, inner shadow, bevel, noise, blur, colour grade and text shadow.
- **Layers and files.** Manage layers and groups, then save a local `.doodle` file to return to later. In Chrome and Edge, Save writes back to the same file.
- **Recovery.** Unsaved work comes back if the tab closes.
- **Command palette.** Press Ctrl+K (Cmd+K on Mac) to find any command.
- **Presets.** Explore the Game Boy Color, iPod Classic and iPod (Gen 1) presets, or begin with a blank canvas.
- **Export.** Preview and download standalone HTML and CSS or a Web Component, with no framework required. Designs with images or fonts download as a ZIP.

![Game Boy Color with its display selected and screen group expanded in Layers](assets/game-boy-color-screen-editor-1920x1080.png)

## Get started

1. Open [doodledev.app](https://doodledev.app/) on your desktop.
2. Choose a preset or a blank canvas and start designing.
3. Select **Code Preview** to review your design, choose an export format, and download it.

Exports contain the visual design. Interactive behaviour can be added separately when you use it in a site.

![iPod Classic design in DoodleDev's HTML export preview](assets/ipod-classic-export-1920x1080.png)
